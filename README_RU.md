# Zero-Cross Compressor

**Zero-Cross Compressor** — это офлайн-компрессор аудиофайлов с настройкой через INI-файл и многопоточной пакетной обработкой любых форматов, поддерживаемых **FFmpeg**.

Программа анализирует трек целиком, автоматически подбирает глубину сжатия под целевой показатель **Dynamic Range (DR)** и выполняет финальную нормализацию сигнала без разрушения транзиентов.

## Принцип работы

В основе алгоритма лежит покадровая работа с **пересечениями PCM-сигнала через ноль (zero-crossings)**:

1. **Сохранение атак и структуры волны:** алгоритм находит точки пересечения сигнала с нулевым уровнем и линейно масштабирует амплитуду внутри интервалов между соседними нулями. Благодаря этому форма полуволн и переходные процессы не искажаются — **атака ударных и перкуссии остаётся нетронутой**.

2. **Автоматический подбор степени сжатия:** динамический диапазон оценивается по стандарту **TT Dynamic Range** (аналогично плагину `foo_dr_meter`). Компрессор вычисляет исходный DR трека, сравнивает его с целевым значением из конфигурации и ослабляет только пиковые полуволны до достижения заданного DR.

3. **Нормализация:** после компрессии уровень сигнала приводится к заданному пиковому потолку (по умолчанию `-0.3 дБ`).

## Характер звучания и особенности

* **Умеренная компрессия:** не окрашивает звук и не «замыливает» атаку. Вносимые нелинейные искажения сопоставимы с работой усилителя класса B, но настолько малы, что находятся ниже уровня обычного дизеринга.

* **Экстремальная компрессия:** при глубоком сжатии пиковых полуволн возникает генерация инфразвуковых составляющих (ниже `20 Гц`) — эффект схож с просадкой питания усилителя класса B под тяжёлой нагрузкой. При агрессивных настройках DR рекомендуется дополнительно применять обрезной фильтр низких частот (High-Pass / ФВЧ).

* **Рекомендуемые значения DR:** `8–9 дБ` (значение по умолчанию — `9 дБ`) позволяют получить плотное, но живое звучание, избегая пережатости современных мастеров на уровне `5–6 дБ` которые трудно назвать музыкой вообще.

## Быстрый старт

### 1. Настройка конфигурации

Откройте INI-файл рядом с программой и задайте нужные параметры:

* целевой уровень **DR** (по умолчанию `9`);

* потолок нормализации в дБ (по умолчанию `-0.3`);

* директорию для сохранения готовых файлов (если не указана, автоматически создаётся папка `Output` рядом с исполняемым файлом).

### 2. Обработка файлов

1. Выделите один или несколько аудиофайлов (или папок, если поддерживается) и перетащите их прямо на исполняемый файл программы (**Drag & Drop**).

2. Откроется окно терминала, в котором запустится многопоточная обработка всех треков.

3. Готовые файлы появятся в указанной выходной директории.

## Требования

* Наличие dll библиотек **FFmpeg** в папке с программой для декодирования и кодирования аудиоформатов.
